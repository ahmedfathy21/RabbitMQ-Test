# RabbitMQ Test Project

This project demonstrates the use of RabbitMQ for message queuing in Python. It includes a receiver that listens for messages on a specified queue and processes them accordingly. The receiver simulates a time-consuming task to illustrate message handling and acknowledgment.

## Requirements
- Python 3.x
- pika library

## Setup
1. Install the required libraries using `pip install pika`.
2. Ensure RabbitMQ server is running locally.

## Usage
Run the receiver script to start processing messages from the queue.
